# 上班总时间 WorkHoursApp v1.6

一个简单的离线 Android 工时统计 App。

## 默认自动计入工时
- 不需要每天手动设置。
- App 会根据“设置”中的工作日和默认每天工时，自动计算本月从 1 日到今天的工时。
- 例如设置周一至周五为工作日、每天 8 小时，那么普通工作日会自动按 8 小时计入。
- 即使几天没有打开 App，再次打开时也会根据日期重新计算，不会漏记中间的工作日。
- 公共假期自动按 0 小时处理。
- 只有主动修改某一天时，才使用当天的例外状态覆盖默认规则。
- 例外状态包括：请假、手动休息、自定义当天工时。
- “恢复自动”会清除当天例外记录，让该日期重新跟随工作日和默认工时设置。

## 状态修改二次确认
- 点击普通日期后，可以明确选择：正常上班、请假、休息。
- 选择状态本身不会立即修改数据。
- 点击“保存”后，会先显示日期、目标状态、工时以及请假原因摘要。
- 只有再次点击“确认修改”后才真正保存，避免误触。
- “恢复自动”也增加二次确认，确认后才会清除当天手动状态、工时和请假原因。
- 手动“休息”会作为独立状态保存，并显示“休息 · 0 小时 · 已修改”。

## 请假描述
- 选择“请假（0 小时）”后，可以填写可选的请假原因/描述。
- 例如：看医生、年假、家庭原因。
- 请假原因会保存在当天记录中，再次打开当天时会自动带出，方便修改。
- “本月请假”汇总会显示日期、请假原因和 0 小时。
- 每日记录也会显示“请假 · 原因 · 0 小时”。

## 英国公共假期
- 按 England & Wales Bank Holiday 规则识别公共假期。
- 公共假期强制按 0 小时计算，不计入本月总工时。
- 总工时卡片内单独列出“本月公共假期”的日期、名称和 0 小时。
- 每日记录里也会标记“公共假期 · 0 小时”，与普通休息日区分。
- 公共假期不能手动改成工作工时，避免误计入总时间。

## 其他功能
- 默认周一至周五为工作日，可自行修改。
- 默认每天 8 小时，可自行修改。
- 自动按日期计算本月截至今天的工时。
- 所有数据保存在本机 SharedPreferences，不需要网络权限。

## 最低系统
Android 8.0 (API 26)
