# 上班总时间 WorkHoursApp v1.12

一个简单的离线 Android 工时统计 App。

## 新增：按星期查看
- 主页新增“按星期查看”。
- 每周按周一到周日统计，可用左右按钮查看上一周或下一周。
- 当前周只统计到今天，未来日期不会提前计入。
- 历史周统计完整一周。
- 每周显示总工时、工作天数、请假天数、公共假日天数、手动休息天数、自定义工时天数。
- 同时逐日显示正常上班、请假及原因、公共假日、休息、自定义工时和非工作日。
- 星期统计同样遵守工作开始日期。

## 公共假日标注
- 界面中原来的“假期”统一改为“公共假日”。
- 月度汇总、月历、每周统计、日期范围统计和异常记录都统一使用“公共假日”。

## 工作开始日期
- 设置页可以选择一个可选的“工作开始日期”。
- 例如设置为 2026-05-15，则 2026-05-15 之前的日期不会计入工时。
- 月历中开始日期之前会显示“未开始”，不能修改，也不会进入月度统计。
- 历史月份和历史星期不会早于工作开始日期。
- 日期范围统计会自动从工作开始日期起算。
- 清除工作开始日期后，会恢复查看和统计全部历史。

## 日期范围统计
- 可以选择开始日期和结束日期统计任意一段时间。
- 支持跨月、跨年。
- 最晚只统计到今天。
- 显示总工时、工作、请假、公共假日、休息和自定义工时数量。
- 同时列出这段时间内的异常明细。

## 月度查看 + 历史记录
- 主页顶部提供上个月 / 下个月切换。
- 当前月份只统计到今天；历史月份统计完整整月。
- 顶部汇总显示本月总工时、实际工作天数、请假天数、公共假日天数。
- 7 列月历显示正常工时、请假、休息、公共假日、自定义工时和未开始日期。
- 普通工作日直接自动计入，不需要每天手动设置。

## Android 支持范围
- 最低支持 Android 12（API 31）。
- 目标支持 Android 17（API 37）。
- compileSdk = 37，targetSdk = 37，minSdk = 31。

## 根据上下班时间自动计算工时
- 设置上班时间、下班时间和休息分钟数后自动计算每天应计工时。
- 默认示例：09:00 上班、17:30 下班、休息 30 分钟 = 每天 8 小时。
- 支持跨午夜班次。

## 默认自动计入与例外覆盖
- 工作日默认按设置自动计算。
- 公共假日自动 0 小时。
- 请假固定 0 小时并可填写原因。
- 手动休息固定 0 小时。
- 某天实际工时不同，可单独设置当天工时。
- 恢复自动会删除当天例外，让其重新跟随默认设置。

## 防误触
- 日期状态支持正常上班、请假、休息。
- 状态选择不会立即保存。
- 点击保存后会显示修改摘要并要求二次确认。
- 恢复自动同样需要确认。

## 英国公共假日
- 按 England & Wales Bank Holiday 规则识别。
- 公共假日不计工时，并在月历、周统计、异常记录和日期范围统计中体现。

## 数据
- 所有设置、请假、休息和单日覆盖数据保存在本机 SharedPreferences。
- 不需要网络权限。
