# 上班总时间 WorkHoursApp v1.17

一个简单的离线 Android 工时统计 App。

## 新增：数据备份 / 导入 / 迁移
- 设置页新增“数据备份与迁移”。
- 可以通过系统文件选择器把全部 App 数据导出到手机、U 盘、网盘或其他 Document Provider。
- 导出文件为 JSON 格式，默认文件名类似 `WorkHoursApp-backup-20260824-211700.json`。
- 备份包含：全局上下班时间、休息分钟数、工作开始日期、每周休息日、每月固定休息日期、请假状态和原因、手动休息、单日自定义上下班时间以及所有历史覆盖记录。
- 不需要申请存储权限。
- 在另一台手机安装 App 后，可通过“导入 / 恢复数据”选择备份文件完成迁移。
- 导入前会先检查 App 标识、备份格式和所有数据项，损坏或不兼容的文件不会覆盖当前数据。
- 验证通过后会显示备份时间和数据项目数量，并要求再次确认。
- 确认导入后会覆盖当前 App 数据；建议导入前先导出当前数据作为备份。

## 状态栏 / 导航栏适配
- 主界面和设置界面统一适配系统栏安全区域。
- 自动避开顶部状态栏、刘海/打孔区域以及底部手势条或三键导航栏。
- Android 12～17 都按设备实际 WindowInsets 动态处理。

## 单日按上下班时间修改
- 点击月历中的某一天后，可以单独选择当天上班时间、下班时间和休息分钟数。
- App 自动计算这一日的最终工时，并在确认修改前显示完整摘要。
- 单日时间设置独立保存；恢复自动后重新跟随全局工作时间和休息规则。

## 自动休息规则
- 设置页可以选择每周休息日，也可以设置每月固定休息日期，例如 `5, 15, 28`。
- 自动休息日按 0 小时计算，并在月历、星期统计和日期范围统计中显示。
- 单日手动修改可以覆盖自动休息规则。

## 周末颜色
- 月历中的周六、周日使用不同底色显示。
- 今天、请假、自定义工时和公共假日颜色优先于周末底色。

## 按星期查看
- 支持按周一到周日查看每周总工时和逐日记录。
- 当前周只统计到今天；历史周统计完整一周。

## 工作开始日期
- 可以设置可选的工作开始日期。
- 开始日期之前不会计入月度、星期和日期范围统计。

## 日期范围统计
- 可以选择任意开始日期和结束日期，支持跨月、跨年。
- 显示总工时、工作、请假、公共假日、休息和自定义工时数量及明细。

## 月度查看 + 历史记录
- 支持上个月 / 下个月切换。
- 当前月份只统计到今天，历史月份统计完整整月。
- 月历显示正常工时、休息、请假、公共假日、自定义工时和未开始日期。

## 根据上下班时间自动计算工时
- 设置上班时间、下班时间和休息分钟数后自动计算每天应计工时。
- 默认示例：09:00 上班、17:30 下班、休息 30 分钟 = 每天 8 小时。
- 支持跨午夜班次。

## 防误触
- 单日状态支持正常上班、请假、休息。
- 保存和恢复自动都需要二次确认。

## 英国公共假日
- 按 England & Wales Bank Holiday 规则识别。
- 公共假日自动 0 小时，并在月历、周统计、异常记录和日期范围统计中体现。

## Android 支持范围
- minSdk = 31（Android 12）
- targetSdk = 37（Android 17）
- compileSdk = 37

## 数据
- 所有数据默认保存在本机 SharedPreferences。
- 支持手动导出 / 导入完整备份进行迁移。
- 不需要网络权限或存储权限。
