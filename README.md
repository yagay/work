# 上班总时间 WorkHoursApp v1.15

一个简单的离线 Android 工时统计 App。

## 新增：单日按上下班时间修改
- 点击月历中的某一天后，正常上班状态不再直接填写“当天工时”。
- 可以单独选择当天上班时间、当天下班时间和当天休息分钟数。
- App 会自动计算这一日的最终工时。
- 上下班时间使用系统时间选择器，减少手动输入错误。
- 确认修改前会显示日期、状态、上班时间、下班时间、休息分钟数和最终工时。
- 单日时间设置会独立保存，再次打开当天时会自动显示之前设置的时间。
- 如果当天时间与全局默认设置完全相同，则不会额外保存覆盖记录，仍继续跟随全局自动设置。
- 自定义工时明细会同时显示对应的上下班时间和休息分钟数。
- 切换为请假或休息时会清除当天自定义上下班时间。
- “恢复自动”会清除当天自定义时间，让当天重新跟随全局工作时间及休息规则。

## 自动休息规则
- 设置页可以直接选择“每周休息日”。
- 可以把周六、周日设为休息，也可以选择周一到周日中的任意一天作为固定休息日。
- 默认保持周一到周五工作、周六周日休息，并兼容旧版本保存的工作日设置。
- 可以设置“每月固定休息日期”，例如输入 `5, 15, 28`，表示每个月的 5 日、15 日、28 日自动休息。
- 每月固定休息日期支持 1～31；某个月不存在的日期会自然跳过。
- 自动休息日按 0 小时计算，并在月历中显示“休息”。
- 按星期查看会显示“休息 · 自动规则”，日期范围统计也会把自动休息日计入休息天数。
- 单日手动修改可以覆盖自动休息规则，例如固定休息日临时上班，可单独设置当天上下班时间。

## 周末颜色
- 月历中的周六、周日使用不同底色显示。
- 今天、请假、自定义工时和公共假日颜色优先于周末底色。

## 按星期查看
- 主页支持按周一到周日查看每周工时。
- 当前周只统计到今天；历史周统计完整一周。
- 显示总工时、工作、请假、公共假日、休息和自定义工时天数。
- 逐日显示正常上班、请假、公共假日、自动/手动休息和自定义工时。

## 工作开始日期
- 可以设置可选的工作开始日期。
- 开始日期之前不会计入工时，也不会进入月度、星期和日期范围统计。

## 日期范围统计
- 可以选择任意开始日期和结束日期。
- 支持跨月、跨年。
- 显示总工时、工作、请假、公共假日、休息和自定义工时数量及明细。

## 月度查看 + 历史记录
- 支持上个月 / 下个月切换。
- 当前月份只统计到今天，历史月份统计完整整月。
- 7 列月历显示正常工时、休息、请假、公共假日、自定义工时和未开始日期。

## 根据上下班时间自动计算工时
- 设置上班时间、下班时间和休息分钟数后自动计算每天应计工时。
- 默认示例：09:00 上班、17:30 下班、休息 30 分钟 = 每天 8 小时。
- 支持跨午夜班次。

## 防误触
- 单日状态支持正常上班、请假、休息。
- 保存和恢复自动都需要二次确认。

## 英国公共假日
- 按 England & Wales Bank Holiday 规则识别。
- 公共假日自动 0 小时，并在月历、周统计、异常记录和日期范围统计中体现。

## Android 支持范围
- minSdk = 31（Android 12）
- targetSdk = 37（Android 17）
- compileSdk = 37

## 数据
- 所有设置、休息规则、请假和单日覆盖数据保存在本机 SharedPreferences。
- 不需要网络权限。
