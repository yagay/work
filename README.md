# 上班总时间 WorkHoursApp v1.18

一个简单的离线 Android 工时和工资统计 App。

## 新增：工资自动计算
- 新增“工资统计”页面，可设置两种工资模式：按小时工资、按月固定工资。
- 按小时模式：当天实际工时 × 每小时工资，自动得到当天工资。
- 按月模式：每月固定工资按当月计划上班日平均分摊为每天工资。
- 月薪模式下，公共假日和请假默认保留当天工资；只有明确标记为“扣工资”的日期才扣除当天工资。
- 可以选择任意历史日期，查看当天状态、工时、扣除前工资、扣除金额和实际工资。
- 每一天都可以单独设置“这一天需要扣工资”或取消扣工资。
- 支持按星期查看：显示这一周总工时、总工资、扣工资金额、扣工资天数和每天工资明细。
- 支持按月查看：显示当月工时、工作天数、工资、已扣金额、扣工资天数以及逐日工资明细。
- 当前周和当前月只统计到今天，历史周/月显示完整历史数据。
- 工资相关设置和扣工资日期会自动包含在完整 JSON 备份中，可以一起迁移到新手机。
- 金额默认使用英镑 £ 显示。

## 数据备份 / 导入 / 迁移
- 设置页提供“数据备份与迁移”。
- 可以通过系统文件选择器把全部 App 数据导出到手机、U 盘、网盘或其他 Document Provider。
- 导出文件为 JSON 格式。
- 备份包含全局上下班时间、休息规则、工作开始日期、请假及原因、手动休息、单日自定义上下班时间、工资设置、扣工资日期以及全部历史覆盖记录。
- 不需要申请存储权限。
- 在另一台手机安装 App 后，可通过“导入 / 恢复数据”选择备份文件完成迁移。
- 导入前会先校验备份，确认后才覆盖当前数据。

## 状态栏 / 导航栏适配
- 主界面、设置界面和工资统计界面都会避开状态栏、刘海/打孔区域以及底部手势条或三键导航栏。
- Android 12～17 按设备实际 WindowInsets 动态处理。

## 单日按上下班时间修改
- 点击月历中的某一天后，可以单独选择当天上班时间、下班时间和休息分钟数。
- App 自动计算这一日最终工时。
- 单日时间设置独立保存；恢复自动后重新跟随全局工作时间和休息规则。

## 自动休息规则
- 设置页可以选择每周休息日，也可以设置每月固定休息日期，例如 `5, 15, 28`。
- 自动休息日按 0 小时计算，并在月历、星期统计和日期范围统计中显示。
- 单日手动修改可以覆盖自动休息规则。

## 周末颜色
- 月历中的周六、周日使用不同底色显示。
- 今天、请假、自定义工时和公共假日颜色优先于周末底色。

## 按星期查看
- 支持按周一到周日查看每周总工时和逐日记录。
- 当前周只统计到今天；历史周统计完整一周。

## 工作开始日期
- 可以设置可选的工作开始日期。
- 开始日期之前不会计入月度、星期、日期范围和工资统计。

## 日期范围统计
- 可以选择任意开始日期和结束日期，支持跨月、跨年。
- 显示总工时、工作、请假、公共假日、休息和自定义工时数量及明细。

## 月度查看 + 历史记录
- 支持上个月 / 下个月切换。
- 当前月份只统计到今天，历史月份统计完整整月。
- 月历显示正常工时、休息、请假、公共假日、自定义工时和未开始日期。

## 根据上下班时间自动计算工时
- 设置上班时间、下班时间和休息分钟数后自动计算每天应计工时。
- 默认示例：09:00 上班、17:30 下班、休息 30 分钟 = 每天 8 小时。
- 支持跨午夜班次。

## 英国公共假日
- 按 England & Wales Bank Holiday 规则识别。
- 公共假日自动 0 工时，并在月历、周统计、异常记录和日期范围统计中体现。

## Android 支持范围
- minSdk = 31（Android 12）
- targetSdk = 37（Android 17）
- compileSdk = 37

## 数据
- 所有数据默认保存在本机 SharedPreferences。
- 支持手动导出 / 导入完整备份进行迁移。
- 不需要网络权限或存储权限。
