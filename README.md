# 上班总时间 WorkHoursApp v1.4

一个简单的离线 Android 工时统计 App。

## 新增：请假描述
- 勾选“请假（0 小时，不计入总工时）”后，可以填写可选的请假原因/描述。
- 例如：看医生、年假、家庭原因。
- 请假原因会保存在当天记录中，再次打开当天时会自动带出，方便修改。
- “本月请假”汇总会显示日期、请假原因和 0 小时。
- 每日记录也会显示“请假 · 原因 · 0 小时”。
- 取消请假或选择“恢复自动”时，对应的请假描述也会清除。

## 请假
- 点击普通日期可以勾选“请假（0 小时，不计入总工时）”。
- 请假当天固定按 0 小时计算，不计入本月总工时。
- 总工时卡片内单独列出“本月请假”。
- 请假状态与普通休息日、手动设置为 0 小时区分保存。

## 英国公共假期
- 按 England & Wales Bank Holiday 规则识别公共假期。
- 公共假期强制按 0 小时计算，不计入本月总工时。
- 总工时卡片内单独列出“本月公共假期”的日期、名称和 0 小时。
- 每日记录里也会标记“公共假期 · 0 小时”，与普通休息日区分。
- 公共假期不能手动改成工作工时，避免误计入总时间。

## 其他功能
- 默认周一至周五为工作日，可自行修改。
- 默认每天 8 小时，可自行修改。
- 自动按日期计算本月截至今天的工时。
- 点击普通日期可手动修改当天工时或恢复自动。
- 所有数据保存在本机 SharedPreferences，不需要网络权限。

## 最低系统
Android 8.0 (API 26)
