# 上班总时间 WorkHoursApp v1.8

一个简单的离线 Android 工时统计 App。

## Android 支持范围
- 最低支持 Android 12（API 31）。
- 目标支持 Android 17（API 37）。
- compileSdk = 37，targetSdk = 37，minSdk = 31。
- 主要适配 Android 12、13、14、15、16、17。

## 根据上下班时间自动计算工时
- 不再要求手动填写“每天固定多少小时”。
- 设置上班时间、下班时间和休息分钟数后，App 自动计算每天应计工时。
- 默认示例：09:00 上班、17:30 下班、休息 30 分钟 = 每天 8 小时。
- 支持跨午夜班次，例如 22:00 上班、06:00 下班会按第二天下班计算。
- 正常工作日会自动按计算出的每日工时计入，不需要每天手动设置。
- 即使几天没有打开 App，再次打开也会按日期和当前工作设置重新计算，不会漏记普通工作日。
- 单日修改为与默认工时相同的“正常上班”时，不保存手动覆盖，因此以后修改默认上下班时间后该日期仍会跟随自动规则。

## 默认自动计入与例外覆盖
- App 根据设置好的工作日自动统计本月从 1 日到今天的工时。
- 公共假期自动按 0 小时处理。
- 请假固定按 0 小时处理，并可填写请假原因。
- 手动休息固定按 0 小时处理。
- 如某一天实际工时与默认不同，可单独填写当天工时进行覆盖。
- “恢复自动”会清除当天例外记录，让该日期重新跟随工作日和上下班时间设置。

## 状态修改二次确认
- 点击普通日期后，可以选择：正常上班、请假、休息。
- 选择状态本身不会立即修改数据。
- 点击“保存”后，会显示日期、目标状态、工时和请假原因摘要。
- 只有再次点击“确认修改”后才真正保存，避免误触。
- “恢复自动”也需要二次确认。

## 请假描述
- 选择“请假（0 小时）”后，可以填写可选的请假原因/描述。
- 例如：看医生、年假、家庭原因。
- 请假原因会保存在当天记录中，再次打开当天时会自动带出。
- “本月请假”汇总和每日记录都会显示请假原因。

## 英国公共假期
- 按 England & Wales Bank Holiday 规则识别公共假期。
- 公共假期强制按 0 小时计算，不计入本月总工时。
- 总工时卡片单独列出“本月公共假期”的日期、名称和 0 小时。
- 每日记录也会标记“公共假期 · 0 小时”。
- 公共假期不能手动改成工作工时。

## 数据
- 所有设置、请假、休息和单日覆盖数据保存在本机 SharedPreferences。
- 不需要网络权限。
