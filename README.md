# 上班总时间 WorkHoursApp v1.9

一个简单的离线 Android 工时统计 App。

## 新布局：月度查看 + 历史记录
- 主页顶部提供“上个月 / 下个月”切换，可查看任意历史月份。
- 当前月份只统计到今天；历史月份统计完整整月。
- 顶部汇总显示：本月总工时、实际工作天数、请假天数、公共假期天数。
- 中间使用 7 列月历显示每日状态：正常工时、请假、休息、公共假期、自定义工时。
- 普通工作日直接显示自动计算的工时，不需要每天手动设置。
- 请假、休息、自定义工时会在月历中明显标记。
- 月历下方只列“本月异常记录”，避免重复显示所有正常工作日。
- 异常记录包括：公共假期、请假及原因、手动休息、自定义工时。
- 点击可编辑的历史日期，可以继续修改或恢复自动计算。
- 设置从主页移到独立“工作时间设置”页面，主页更简洁。

## Android 支持范围
- 最低支持 Android 12（API 31）。
- 目标支持 Android 17（API 37）。
- compileSdk = 37，targetSdk = 37，minSdk = 31。

## 根据上下班时间自动计算工时
- 设置上班时间、下班时间和休息分钟数后，App 自动计算每天应计工时。
- 默认示例：09:00 上班、17:30 下班、休息 30 分钟 = 每天 8 小时。
- 支持跨午夜班次。
- 正常工作日自动计入，无需逐日确认。

## 默认自动计入与例外覆盖
- 工作日默认按设置自动计算。
- 公共假期自动按 0 小时处理。
- 请假固定 0 小时，并可填写原因。
- 手动休息固定 0 小时。
- 某天实际工时不同，可单独设置当天工时。
- “恢复自动”会删除当天例外，让其重新跟随默认设置。

## 防误触
- 日期状态支持：正常上班、请假、休息。
- 状态选择不会立即保存。
- 点击保存后还会显示修改摘要并要求二次确认。
- “恢复自动”同样需要确认。

## 英国公共假期
- 按 England & Wales Bank Holiday 规则识别。
- 公共假期不计工时，并在月历和异常记录中体现。

## 数据
- 所有设置、请假、休息和单日覆盖数据保存在本机 SharedPreferences。
- 不需要网络权限。
